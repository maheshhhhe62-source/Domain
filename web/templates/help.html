🚸 Help & Guide

How to use Spidey Web Dumper

📕 Full Pipeline

  1. 🥇 Keywords — Generate seed keywords
  2. 🥈 Dorks — Convert keywords to dorks
  3. 🌊 Proxy — Add and check proxies
  4. 🛰️ Parser — Dorks → URLs
  5. 🦠 SQLi Scanner — Test URLs for vulns
  6. 🕳️ Dumper — SQLMap → CC / Fullz
  7. 📁 Files — Download your data

📖 Step-by-Step Guide

Step 1: Generate Keywords

Go to Keywords page. Enter seeds like:

shop, payment, checkout, login, admin, cart

Set count (e.g. 1000). Click Generate.

Step 2: Generate Dorks

Go to Dorks page. Paste keywords. Choose type:

  • normal — Standard SQLi dorks
  • hq — High-quality SQLi dorks
  • country — Country-targeted
  • cms — WordPress/Joomla/etc.
  • exposed — .env / config files

Step 3: Add Proxies

Go to Proxy page. Paste proxies (one per line) or upload file. Click Check Live to filter dead ones.

Step 4: Parse Dorks → URLs

Go to Parser page. Paste your dorks. Click Run. Wait for URLs.

Step 5: SQLi Scan

Go to SQLi Scanner. Paste URLs from step 4. Click Start Scan. Vulnerable URLs will be listed.

Step 6: Dump

Go to Dumper. Paste vulnerable URLs. Adjust SQLMap settings. Click Start Dump. Download CC + Fullz files.

❓ FAQ

Q: My scan is slow. Why?

A: Add more proxies. Without proxies, engines block your IP.

Q: No URLs found?

A: Try different dorks (hq or exposed). Or add more proxies.

Q: Dump failed?

A: Check if URL is actually vulnerable first (SQLi Scanner). Use higher level/risk.

Q: Quota exceeded?

A: Upgrade your plan or redeem a new license key.
